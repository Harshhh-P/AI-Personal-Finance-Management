18. ANOMALY DETECTION
==================================================

Endpoint:

GET /analytics/anomalies

Logic:

- Only current user's expense transactions
- Requires at least 3 expense transactions
- Calculate:
  mean + 2 × standard deviation
- Transactions above this threshold are marked as anomalies.

Returned information includes:

id
date
amount
category
description
threshold
reason

If fewer than 3 expenses:

"Not enough expense data for anomaly detection."
